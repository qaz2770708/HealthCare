# 验证记录

验证环境：Windows x64，.NET SDK 10.0.100，ASP.NET Core 10.0.0，SQLite，Codex 内置 Chromium 浏览器。

- Debug / Release 构建：零警告、零错误。
- JavaScript 语法检查：通过。
- `tests/integration.py`：22 项集成检查通过，使用独立临时数据库；另含失败密码锁定和登录限流验证。
- HTTP 实测覆盖：匿名访问/CSRF、三类用户登录、统计、前台病历隔离、医生收费隔离、患者输入验证与并发版本、医生/患者号源冲突、非法预约时间、提前报到拒绝、取消释放时段、医生本人预约隔离、跨医生接诊拒绝、病历草稿/锁定、自动账单/重复收款、随访、员工、审计、密码变更会话失效、重启后数据保持。
- 浏览器验收：登录、工作台布局、患者新建及列表更新、预约检索/时段选择/预约提交、病历草稿/完成、自动生成账单、模拟收款登记。
- 响应式检查：390 × 844 宽度下导航可操作，修复并复核页面横向溢出；桌面视图恢复后无浏览器控制台错误。
- SQLite 在线备份：生成快照并通过 integrity_check。
- 发布程序验收：独立端口启动、提供前端、登录、读取初始化数据库与手机样式；首次 Production 启动缺少初始化密码时按预期拒绝启动。

未执行真实机构数据验收、压力测试、多实例部署、医保/支付/硬件集成或正式医疗文书合规验收。
